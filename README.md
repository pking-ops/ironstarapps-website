# IronStar Apps Website Build

Static website package based on the uploaded mockup layout and look.

## Includes
- index.html
- apps.html
- consulting.html
- security.html
- login.html
- contact.html
- styles.css
- script.js
- assets folder

## Deploy to Vercel
1. Unzip this file.
2. Upload the contents to GitHub.
3. Import the repo into Vercel.
4. Framework Preset: Other.
5. Leave Build Command blank.
6. Leave Output Directory blank.
7. Deploy.

## Squarespace Domains
Squarespace Domains controls DNS. Host this static site on Vercel/Netlify/Cloudflare Pages, then point ironstarapps.com DNS to that host.
